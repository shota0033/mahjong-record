# 麻雀成績（自分用 成績管理PWA）

iPhone の Safari で「ホーム画面に追加」して使う、オフライン対応の成績管理アプリです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `theme.js` | 着せ替え（設定タブの「色の設定」） |
| `manifest.json` / `sw.js` / `icons/` | PWA（ホーム画面追加・オフライン動作） |
| `gas/Code.gs` | クラウド自動バックアップ用 Google Apps Script（GitHubには置かなくてOK） |
| `tests/` / `package.json` | 自動テスト（公開には不要） |

## ポイント計算

`(素点 - 30000) / 1000 + 順位点`

| 順位 | 1着 | 1-2着同点 | 2着 | 2-3着同点 | 3着 | 3-4着同点 | 4着 |
|---|---|---|---|---|---|---|---|
| 順位点 | +50 | +30 | +10 | 0 | -10 | -20 | -30 |

着順分布では、同点は両方の着順に0.5回ずつ数えます（例: 1-2着同点 → 1着0.5回・2着0.5回）。

## オンレート（マーチャオ）の収支計算

- 半荘ごとに入力するのは「順位（1〜4、同点なし）」と「やりとりした金額（±、100円単位）」
- 実収支: 1着は `入力額 − (ゲーム代350円 × 4人 + トップ賞400円)`、2〜4着は入力額そのまま
- ゲーム代・トップ賞は半荘ごとに記録するので、将来の料金改定で過去の収支は変わらない（`app.js` の `SHOPS` で設定）
- 収支 = 半荘収支の合計 + チップ収支（終了時の持ちチップ − 開始時の持ちチップ）
- 最終収支 = 収支 − 追加費用（フード代など。クーポン等での減額はマイナスで入力）

## GitHub Pages で公開する（Windows）

### 方法A: ブラウザだけで行う
1. GitHub で新しいリポジトリを作る（例: `mahjong-record`、Public）
2. 「Add file → Upload files」で、次のファイルをドラッグ＆ドロップしてコミットする
   `index.html` `style.css` `app.js` `theme.js` `manifest.json` `sw.js` `icons` フォルダ
3. Settings → Pages → Branch を `main` / `/(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/mahjong-record/` で公開される

### 方法B: git コマンド
```powershell
cd C:\麻雀成績管理
git init
git add index.html style.css app.js theme.js manifest.json sw.js icons README.md
git commit -m "初版"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/mahjong-record.git
git push -u origin main
```
その後、方法Aの手順3と同じ操作で Pages を有効にします。

### アプリを更新したとき
1. `app.js` の `APP_VERSION` と `sw.js` の `VERSION` を**同じ値に**上げる（例: `1.1.0` → `1.2.0`）
2. `npm test` で全件成功を確認する
3. 変更したファイルを GitHub にアップロードする（公開に必要なのは `index.html` `style.css` `app.js` `theme.js` `manifest.json` `sw.js` `icons/` だけ）
4. iPhone でアプリを開くと、ホーム画面に「新しいバージョンがあります［更新する］」が出るので押す
   （出ないときはアプリを完全に閉じてから開き直す）

## 自動テスト
```powershell
cd C:\麻雀成績管理
npm install   # 初回のみ
npm test
```
ポイント計算、入力チェック、取消、連打防止、保存データの保護、バックアップ送信などを確認します。
修正のたびに実行し、「全 N 件成功」と出ることを確認してから公開してください。

## iPhone に入れる
1. Safari で公開URLを開く
2. 共有ボタン → 「ホーム画面に追加」
3. 以降はホーム画面のアイコンから起動する（Safari で開いた場合とデータは別になるので注意）

## データの保護

1. **端末内保存**: 半荘を確定するたびに端末（localStorage）に保存します。1つ前の状態も予備として残します。保存データが読めなかった場合も元データは消さずに退避します。
2. **クラウド自動バックアップ**（推奨）: 下記の設定をすると、確定・編集のたびに Google ドライブへ自動送信します。電波がないときは「☁ 未送信」と表示し、次にアプリを開いたときに再送します。
3. **手動バックアップ**: 設定タブの「JSONをエクスポート」で、ファイルアプリなどに保存できます。

### クラウド自動バックアップの設定（Windows だけで設定できます）
1. https://script.google.com を開き、「新しいプロジェクト」を作る
2. `gas/Code.gs` の中身を全部貼り付ける
3. `TOKEN` の値を好きな合言葉に書き換えて保存する
4. 右上の「デプロイ」→「新しいデプロイ」→ 歯車アイコンで「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 初回はアクセスの承認を求められるので許可する（「このアプリは確認されていません」と出たら「詳細」→「〜に移動」）
6. 発行された `https://script.google.com/macros/s/.../exec` をコピーする
7. アプリの「成績確認 → 設定」で URL と合言葉を入れ、「保存して送信テスト」を押す

Google ドライブの「麻雀成績バックアップ」フォルダに、`latest.json`（最新）と `backup-日付.json`（日ごとの履歴）が保存されます。
機種変更やデータ消失のときは、設定の「クラウドから復元」を使います。

※ `Code.gs` を修正したときは「デプロイを管理 → 編集 → バージョン: 新バージョン」で更新します（URLは変わりません）。
